# Water_rocket

水火箭 STEM 一日夏令營招生網站。

## 內容

- `index.html`：單頁招生網站，含活動介紹、海報展示、一日流程、FAQ 與 HTML 報名表
- `poster-water-rocket.png`：網站使用的海報主視覺
- `poster-copy.md`：海報文案與 AI 圖像 Prompt
- `google-form-questions.md`：Google 表單欄位規劃
- `notebooklm-course-structure.md`：NotebookLM 課程規劃架構
- `agent.md`：專案工作摘要

## GitHub Pages
